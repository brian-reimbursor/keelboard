# Security

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Open a private GitHub security advisory on this repository, or email the maintainer listed on the GitHub org.

Please include:

- A description of the issue
- Steps to reproduce
- Affected paths or routes
- Any proof-of-concept that stays in your own environment

Do not open a public issue for undisclosed vulnerabilities.

## Demo mode

The default `DEMO_MODE=true` configuration uses a shared in-memory store and well-known demo credentials. That mode is for local exploration only. Do not expose a demo instance to the public internet.
